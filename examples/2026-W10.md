# Week 2026-W10

> Fictional example. Projects, issues and details are made up to show the expected tone and level of detail.

## Summary

Most of the week went to the order-export feature in the customer portal, which reached the test environment on Thursday. A flaky integration test that had blocked merges since last week was traced to a timezone assumption and fixed. On Saturday, offline map caching landed in the Trailmap side project.

## Projects / Context

- Project: Customer Portal; Trailmap (hobby)
- Area: Order export, test suite; offline support
- Role: Software Developer / Full-Stack Developer

## Tasks / Work Performed

- **Order export to CSV (PORTAL-412)**: Built the export endpoint with streaming output so large exports don't load all orders into memory. Added filters for date range and status, and a download button in the UI. Deployed to test on Thursday; QA started verification on Friday.
- **Flaky integration test (PORTAL-398)**: The test failed when run between 23:00 and 01:00 UTC. The fixture created orders with local dates while the query compared UTC. Fixed the fixture and added a test pinned to a time near midnight.
- **Sprint planning (Tuesday)**: Agenda: export scope, release date. Decisions: CSV only in the first version (Excel later if requested); release planned for week 12.
- **Trailmap: offline tiles**: Added a service worker that caches map tiles for a saved route, with a size limit and LRU eviction. Tested on a phone in flight mode.

## Technologies / Tools

- TypeScript, Node.js streams, React
- PostgreSQL
- Service Workers, Cache API
- Claude Code

## Problems Solved

- Memory spikes on large exports, solved with streaming instead of buffering.
- Timezone-dependent test failure, solved by making fixtures UTC-consistent.

## Decisions / Lessons Learned

- Ship CSV first and add Excel only on demand: smaller scope, earlier feedback.
- Tests that touch dates should run at least once with a clock pinned near midnight.

## Results / Impact

- Users can export orders themselves instead of asking support for monthly extracts.
- Unblocked merges for the whole team by fixing the flaky test.
- Trailmap now works without coverage on a saved route.

## Highlights

- Designed and delivered a streaming data-export feature.
- Built offline map support with a bounded tile cache in a side project.

## Next Steps

- Address QA feedback on PORTAL-412 before the week 12 release.
- Trailmap: show cache size and a "clear offline data" button.
